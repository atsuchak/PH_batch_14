## 🛠️ Technologies Learned

Here is the tech stack covered in the course:

- **Foundation:** HTML5, CSS3, JavaScript (ES6+)
- **Frontend:** React, Next.js, Tailwind CSS, TypeScript
- **Backend:** Node.js, Express.js, REST APIs
- **Database:** MongoDB, Mongoose (ODM)
- **UI Libraries:** Hero UI, ShadCN
- **Auth & Security:** BetterAuth, Role-Based Access Control (RBAC), JWT
- **Payment Integration:** Stripe, SSLCommerz
- **Advanced & AI:** AI Assisted Coding, AI Mindset Development
